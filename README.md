# Контекст-бот для MAX

Бот собирает контекст групповых бесед и формирует отчёты обсуждений через YandexGPT. Поддерживает подписки (YooKassa) и обратную связь с поддержкой.

## Что умеет

- сохраняет текстовые сообщения и опросы групповых бесед;
- формирует отчёты: за 1/3/7 дней или за всё время, общий или по выбранным участникам;
- продаёт подписку (безлимитные отчёты) через YooKassa;
- пересылает обращения из `/помощь` сотруднику поддержки с возможностью ответить;
- ограничивает частоту запросов per-chat cooldown;
- переживает перезапуск (состояние в SQLite).

## Команды

- `/начать` — приветствие и инструкция.
- `/отчет` — сформировать отчёт (только в беседах).
- `/помощь` — написать в поддержку (в личном чате).

## Интерфейс

- **Личный чат:** кнопки «⭐ Оформить подписку» и «👤 Личный кабинет» (для администраторов также «🛠 Админ-панель»). Приветственное сообщение содержит инструкцию.
- **Беседа:** отчёт и личный кабинет; администраторам — админ-панель.

Бот не отвечает на обычные сообщения в беседе — он только сохраняет их в контекст.

## Администраторы

Администраторы задаются переменной окружения `ADMIN_IDS` (ID через запятую). У администраторов один полный уровень доступа:

- админ-панель;
- безлимитные отчёты;
- просмотр списка бесед с ботом (название и ID).

Доступ администраторов задаётся переменной окружения `ADMIN_IDS`.

## Лимит отчётов

Лимит бесплатных отчётов принадлежит пользователю, а не чату. Во время активной подписки отчёты безлимитны.

- Бесплатный лимит: 30 отчётов один раз на пользователя.
- Во время активной подписки отчёты безлимитны.

## Подписки

- 1 месяц — 99 ₽;
- 3 месяца — 259 ₽;
- 6 месяцев — 559 ₽.

Срок подписки отображается в личном кабинете. Оплата подтверждается webhook `payment.succeeded` и кнопкой «Проверить оплату». Fulfillment транзакционный и идемпотентный.

## Поддержка

`/помощь` → бот просит описать вопрос и передаёт его сотруднику поддержки. Пока запрос открыт, новые сообщения пользователя и ответы поддержки сохраняются и пересылаются другой стороне. Пользователь или сотрудник поддержки может закрыть запрос; после закрытия `/помощь` создаёт новое обращение. Переписка хранится в SQLite.

## Cooldown

LLM cooldown хранится отдельно для каждого `chat_id` (по умолчанию 10 минут), запускается только после успешного запроса и переживает перезапуск.

## Запуск

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python main.py
```

Каталог `data/` должен сохраняться между перезапусками — там SQLite-база. В личном чате нативная кнопка MAX «Начать» обрабатывается так же, как `/начать`.
