# Контекст-бот для MAX

Бот собирает контекст групповых бесед и формирует отчёты обсуждений через YandexGPT. Поддерживает подписки (YooKassa), промокоды и обратную связь с поддержкой.

## Что умеет

- сохраняет текстовые сообщения и опросы групповых бесед;
- формирует отчёты: за 1/3/7 дней или за всё время, общий или по выбранным участникам;
- продаёт подписку (безлимитные отчёты) через YooKassa;
- поддерживает промокоды на токены и подписки;
- пересылает обращения из `/помощь` сотруднику поддержки с возможностью ответить;
- ограничивает частоту запросов per-chat cooldown;
- переживает перезапуск (состояние в SQLite).

## Команды

- `/начать` — приветствие и инструкция.
- `/отчет` — сформировать отчёт (только в беседах).
- `/помощь` — написать в поддержку (в личном чате).

## Интерфейс

- **Личный чат:** только кнопка «⭐ Оформить подписку» (и «🛠 Админ-панель» для администраторов). Приветственное сообщение содержит инструкцию.
- **Беседа:** отчёт, личный кабинет, промокод, подписка; администраторам — админ-панель.

Бот не отвечает на обычные сообщения в беседе — он только сохраняет их в контекст.

## Администраторы

Администраторы задаются переменной окружения `ADMIN_IDS` (ID через запятую). У администраторов один полный уровень доступа:

- админ-панель;
- безлимитные отчёты;
- создание промокодов на токены и подписки;
- просмотр списка бесед с ботом (название и ID).

Роли `creator` и промокоды на роли больше не используются.

## Токены

Токены принадлежат пользователю, а не чату. Хранение — в `token_grants`; порядок расходования: `subscription` → `promo` → `trial` → `purchased`.

- Trial: 30 токенов один раз на пользователя.
- Во время активной подписки отчёты бесплатны (токены не расходуются).
- Покупка токенов как отдельного товара убрана.

## Подписки

- 1 месяц — 99 ₽ / 30 токенов;
- 3 месяца — 259 ₽ / 90 токенов;
- 6 месяцев — 559 ₽ / 180 токенов.

Подписочные токены действуют до окончания подписки. Оплата подтверждается webhook `payment.succeeded` и кнопкой «Проверить оплату». Fulfillment транзакционный и идемпотентный.

## Промокоды

Награды: токены и подписка (включая вечную). Режимы: `once`, `limited`, `unlimited`. История использования хранится отдельно.

## Поддержка

`/помощь` → бот просит описать вопрос → следующее сообщение пользователя пересылается на `SUPPORT_USER_ID` в формате «Имя, ID, дата/время, текст» с кнопкой «Ответить». Ответ сотрудника доставляется пользователю в личный чат.

## Cooldown

LLM cooldown хранится отдельно для каждого `chat_id` (по умолчанию 10 минут), запускается только после успешного запроса и переживает перезапуск.

## Запуск

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python main.py
```

Каталог `data/` должен сохраняться между перезапусками — там SQLite-база. В личном чате нативная кнопка MAX «Начать» обрабатывается так же, как `/начать`.
